איך זה עובד

  1. טענו מחירון דקל כ־PDF או Excel — המערכת מזהה קודי סעיפים, תיאורים, יחידות ומחירים.
  2. אופציונלי: העלו שרטוט PDF / קובץ DXF / גיליון כמויות — לזיהוי כמויות או קודי סעיפים.
  3. ערכו כמויות, הנחות ומקדמים, וסמנו רק את הסעיפים הרלוונטיים.
  4. ייצאו ל־Excel: קוד, תיאור, יחידה, כמות, מחיר, הנחה, סה״כ, פרק ומע״מ.

קבצי DWG מקוריים הם פורמט סגור של AutoCAD. לשליפת טקסט אמינה המירו ל־PDF או DXF לפני הטעינה.
