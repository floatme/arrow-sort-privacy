# AElinkGenerator

AliExpress affiliate link converter. Intended local path:

`c:\AI\AElinkGenerator\`

## Open

Double-click `open.bat`, or open `index.html` in a browser.

Paste your AliExpress Tracking ID (Portals → Account → Tracking ID), then paste a product URL and convert.

Your Tracking ID stays in this browser only. No server is required.
