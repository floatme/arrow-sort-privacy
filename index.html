Where do I find my Tracking ID?
  1. Sign in at portals.aliexpress.com (AliExpress Affiliate / Star).
  2. Open Account (or Settings) → Tracking ID.
  3. Create one if you do not have it yet, then paste that ID here.
  4. If you already have an affiliate link that looks like s.click.aliexpress.com/deep_link.htm?aff_short_key=..., paste it here and we will pull the key out.
